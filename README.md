# Personal Profile Website

A clean, lightweight personal profile website crafted purely using semantic HTML and hosted permanently via GitHub Pages.

🔗 **Live Website:** https://adityanarayandash100-cloud.github.io/my-profilewebsiteusingonlyhtml/

---

## 📌 About the Project

This project is a minimalist personal digital portfolio created to highlight web fundamentals. It presents essential professional background, skills, and projects without relying on external CSS frameworks, JavaScript libraries, or build configurations.

### Key Highlights
- **100% Pure HTML:** Built purely with structured, semantic HTML tags.
- **Instant Load Time:** Zero framework overhead ensures immediate page rendering on any device or connection.
- **Zero Dependencies:** No package managers, bundlers, or third-party stylesheets.
- **Continuous Deployment:** Hosted directly from the source repository via GitHub Pages.

---

## 🚀 Page Structure

- **Header & Introduction:** Quick bio and introductory background.
- **Academic Background & Technical Skills:** Core technical competencies and educational milestones.
- **Projects & Work:** Showcase of development work and practical implementations.
- **Contact Details:** Direct communication links (Email, LinkedIn, GitHub).

---

## 🛠️ Built With

- **HTML5** – Semantic page markup and layout
- **GitHub Pages** – Cloud static site hosting
